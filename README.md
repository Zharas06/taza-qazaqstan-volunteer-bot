# 109: Volunteers — Telegram-бот взаимопомощи

Двуязычный (🇷🇺 русский / 🇰🇿 қазақша) бот для координации волонтёрской помощи:
жители оставляют заявки, волонтёры рядом их берут и выполняют, получая баллы.

## Возможности

- **Выбор языка** — русский или казахский, выбор сохраняется в базе.
- **Регистрация волонтёра** — ФИО, возраст (14–34), телефон, геолокация.
- **Заявка на помощь** — категория, описание, адрес, телефон, геолокация.
- **Модерация** — новая заявка уходит операторам на одобрение/отклонение.
- **Ближайшие заявки** — волонтёру показываются заявки в радиусе 10 км.
- **Взять / выполнить** — волонтёр берёт заявку, по завершении заявитель
  подтверждает выполнение, и только после этого волонтёру начисляются баллы.
- **Портфолио** — выполненные заявки, баллы, место в рейтинге.
- **Экспорт** — реестры волонтёров и заявок в Excel (команда `/export`).

## Категории и баллы

| Категория | Баллы |
|-----------|-------|
| 🍞 Доставка продуктов / лекарств | 10 |
| 🧹 Уборка дома / двора | 15 |
| 🔧 Бытовой ремонт | 20 |
| 🚨 Чрезвычайная ситуация (ЧС) | 25 |

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

Скопируйте `.env.example` в `.env` и заполните:

```
BOT_TOKEN=токен_от_@BotFather
OPERATOR_IDS=ваш_telegram_id      # узнать id: @userinfobot
```

`OPERATOR_IDS` — это те, кто модерирует заявки и может делать `/export`.
Можно указать несколько id через запятую.

## Запуск

```bash
python bot.py
```

При первом запуске автоматически создаётся база `data/volunteers109.db`.

## Команды

- `/start` — запуск, выбор языка, главное меню
- `/lang` — сменить язык
- `/export` — выгрузить реестры в Excel (только операторы)

## Структура проекта

| Файл | Назначение |
|------|------------|
| `bot.py` | основная логика: меню, регистрация, заявки, модерация |
| `locales.py` | все тексты интерфейса на двух языках |
| `config.py` | настройки: токен, категории, баллы, радиус, возраст |
| `db.py` | работа с SQLite: волонтёры, заявки, язык, гео |
| `reports.py` | экспорт реестров в Excel |
| `test_local.py` | локальный тест базы и экспорта без токена |

## Добавить язык или фразу

Все тексты — в `locales.py`, словарь `TEXTS`. Чтобы изменить фразу,
правьте нужный ключ в блоках `ru` и `kz`. Ключи в обоих блоках должны совпадать.
